# SD Search Engine - Frontend

Frontend da aplicação do Sistema Distribuído de Indexação e Pesquisa de Páginas Web.

## Tecnologias

- **Next.js 14** - Framework React
- **TypeScript** - Type safety
- **React 18** - UI Library

## Instalação

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000) no navegador.

## Build

```bash
npm run build
npm start
```

## Estrutura

```
frontend/
├── src/
│   └── app/           # App Router do Next.js
├── public/            # Arquivos estáticos
├── package.json
├── tsconfig.json
└── next.config.js
```
